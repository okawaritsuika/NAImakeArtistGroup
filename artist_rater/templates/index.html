공유 그림체 ZIP으로 빠르게 설치

Google Drive에서 약 3.10 GB ZIP을 이어받아 SHA-256을 확인하고 이미지 1,687장을 자동으로 풉니다. 자동 다운로드가 안 되면 Drive에서 ZIP 사본을 직접 받은 뒤 로컬 ZIP 설치를 선택하세요.

기존 아카라이브 직접 다운로드 방식도 아래에 그대로 남아 있습니다.

아카라이브에서 직접 받기 (기존 방식)

용량·시간 확인은 저장된 DB로 즉시 계산합니다. 다운로드를 시작하면 고정 저장된 원본 게시글 주소에서 최신 이미지 링크를 게시글별로 받아 곧바로 저장합니다. 사이트의 429 제한을 피하는 안전 속도와 자동 재시도를 사용하며, EXE 옆 data\arca_style_images에 저장합니다.

아직 다운로드하지 않습니다. 먼저 아래 버튼으로 필요한 용량과 시간을 확인하세요.

🔞 게시판 로그인브라우저 로그인 연결 안 됨
지금 쓰는 Chrome 로그인 그대로 연결하기

처음 한 번만 아래 확장을 등록하면, 현재 Chrome의 아카라이브 로그인만 로컬 앱에 전달할 수 있습니다.

  1. 설치 폴더를 엽니다.
  2. Chrome 주소창에 chrome://extensions를 입력하고 개발자 모드에서 압축해제된 확장 프로그램을 로드합니다.
  3. 열린 arca_session_bridge 폴더를 고른 뒤 확장 버튼에서 연결합니다.
