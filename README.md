# Danbooru Artist Rater

Danbooru 작가를 평가하고, 평가 결과로 NovelAI용 그림체 프롬프트를 구성하는 Windows 로컬 도구입니다. 아카라이브의 그림체 공유 게시글과 이미지 메타데이터도 수집·정리할 수 있습니다.

## 다운로드

[v0.1.12 EXE 다운로드](https://github.com/okawaritsuika/NAImakeArtistGroup/releases/download/v0.1.12/DanbooruArtistRater.exe) · [릴리스 및 변경사항](https://github.com/okawaritsuika/NAImakeArtistGroup/releases/tag/v0.1.12) · [아카라이브 소개 본글](https://arca.live/b/aiart/177316727)

업데이트할 때는 기존 EXE 옆의 `data` 폴더를 유지해 주세요.

## 주요 기능

- Danbooru 작가 검색, 샘플 확인, 1~5점 평가
- 평가한 작가로 가중치 기반 그림체 프롬프트 제작
- 공유 그림체 작가 최소·최대 인원 범위 랜덤 및 공유 작가만으로 그림체 구성
- NovelAI 이미지 생성과 생성 결과 관리
- 아카라이브 그림체 공유 게시글 기간 수집 및 링크 직접 추가
- 이미지별 베이스·네거티브·캐릭터 프롬프트 비교
- 평가 작가·NAI 작가 테스트의 작가 단위 출처를 기준 그림과 비교해 그림체 그룹으로 분류·관리
- 추천·조회·게시일 기준 그림체 정렬
- 공유·확정 그림체로 이상형 월드컵 생성, 참가자 갤러리 선택, 대결 자동 저장·이어하기 및 우승 결과 확인

## 이상형 월드컵

헤더의 `이상형 월드컵`은 참가 그림 썸네일이 있는 폴더형 갤러리로
표시됩니다. 폴더를 열어 진행 중인 대회를 이어 하거나 저장된 결과를
확인할 수 있습니다. **새로 만들기**를 누르면 이름 입력, 필터, 참가 그림체
갤러리가 한 화면에 열립니다. 처음에는 그림을 불러오지 않으며, 조건을 설정하고
**필터 적용**을 누르면 후보 개수와 그림 목록을 표시합니다. **전체 / 공유 / 확정 버튼**으로 목록을 바꾸며
참가할 그림체를 고른 뒤, 같은 화면에서 바로 **월드컵 시작**을 누릅니다.
같은 공유 게시글 또는 확정 항목의 이미지는 조건에 맞는 대표 한 장만
표시합니다. **모델**에서 V5 전체·V5 Full Medium·V5 Full·V5 Curated·
V4.5 전체와 세부 모델·Unknown을 선택할 수 있습니다.
자동 선택은 공유·확정 전체를 대상으로 먼저 필터를 적용해 출처별 참가 가능한 그림체
개수를 확인한 다음 참가 규모를 선택합니다. 가능한 2·4·8·16강 등의
규모 또는 **전부 참가**를 선택할 수 있으며, 전부 참가에는 128개 제한이
없습니다. 인원이 2의 거듭제곱이 아니면 첫 라운드에 부전승을 배정합니다.

`자동 선택`으로 뽑힌 그림을 같은 갤러리에서 확인하거나 직접 고릅니다. 갤러리의
전체·공유·확정 버튼으로 갤러리를 전환하거나 선택한 그림만 볼 수 있고,
그림을 눌러 추가·제외할 수 있습니다. 출처를 바꿔도 선택 명단은 유지됩니다.
마우스로 드래그하면 **사각형 영역**이 표시되고 그 영역과 겹친 그림체를
한 번에 선택합니다. 이미 선택된 카드에서 시작하면 영역 안의 선택을 해제합니다.
영역을 줄이면 벗어난 카드는 원래 상태로 돌아가며, Escape로 드래그를 취소할 수
있습니다. 터치에서는 스크롤과 탭 선택을 사용합니다.
**그림 크기** 슬라이더로 한 화면에 보이는 수를 조절하고,
한 페이지에 최대 60개를 볼 수 있습니다. 갤러리는 작은 썸네일을 먼저 사용하며
선택 표시만 갱신해 이미지가 다시 그려지는 일을 줄였습니다.
갤러리 안에서 모델·추천수·태그 포함/미포함 조건을 적용하고 추천수 높은 순·낮은
순으로 정렬할 수 있습니다. 조건에 맞는 전체·출처별 개수와 선택한 개수를
함께 표시합니다. **필터를 바꿔도 이미 선택한 그림체는 유지**되며,
같은 항목이 다른 대표 이미지로 보여도 중복 선택되지 않습니다. 카드의 출처·모델·추천수는
테두리 있는 표시로 한 줄에 모았습니다. **상세 보기**는 갤러리 오른쪽 패널에서 해당
게시물·확정 항목의 다른 그림과 이미지별 프롬프트를 보여 줍니다. 좁은 화면에서는 오른쪽에서
펼쳐지며, 그림 크기를 조절하거나 **← / →** 키와 이전·다음 버튼으로 이미지를 넘길 수 있습니다.
크기 조절 입력에 포커스가 있으면 방향키는 크기를 조절합니다. **Esc / 상세 닫기**로 닫으면
갤러리 위치를 복원하며, 상세를 보거나 닫아도 선택 상태는 유지됩니다.
별도의 선택 완료 단계 없이 현재 선택한 명단 그대로 대회를 시작합니다.
자동 선택 규모와 달라져도 최종 선택이 2개 이상이면 그 인원으로 진행합니다.
후보 개수는 **필터 적용**을 누를 때 확인합니다.

작가와 일반 태그는 **포함할 태그 / 제외할 태그**에서 함께 입력합니다.
두 글자 이상 입력하면 기존 태그 자동완성으로 검색하고, 방향키·Enter나
마우스로 선택할 수 있습니다. 작가를 선택하면 `artist:`가 자동으로 붙습니다.
쉼표나 줄바꿈으로 여러 태그를 입력하며 자동완성은 현재 입력 중인 태그만 바꿉니다.
예를 들어 제외 조건에 `artist:artist_a, monochrome`을 입력하면 어느 태그든
베이스 프롬프트에 있는 **그림체 전체**가 후보에서 빠집니다. 포함 항목은 모두
충족해야 하고, 제외 항목은 하나라도 해당하면 빠집니다. 태그는
**베이스 프롬프트만** 비교하며 가중치·대소문자·밑줄/공백 차이는 무시합니다.
확정 그림체는 현재 저장된 작가·퀄리티·고정 프롬프트를 함께 검사하며,
네거티브·캐릭터 프롬프트는 두 출처 모두 검사하지 않습니다.

`추천수 N 이하 제외`는 공유 후보에만 적용하며 추천수 미상도
제외됩니다. 비워 두면 추천수 제한은 없습니다. 확정 그림체는 추천수 조건에
영향받지 않습니다. 로컬 이미지가 있는 후보에서 선택한 규모만큼 무작위로
뽑거나 전부 선택한 후, 참가 갤러리에서 최종 명단을 확인합니다. 자동 선택은
이미 고른 명단에 중복 없이 추가하며 기존 선택을 지우지 않습니다.
경기마다 자동 저장되므로 목록에서 이어 할 수 있고, 완료 후 우승 그림과
전체 대결 기록을 다시 확인할 수 있습니다. `새로 만들기`는 별도 월드컵을
만듭니다. 원본 공유·확정 이미지 파일을 삭제하면 저장된 결과의 이미지도
표시할 수 없지만 제목·프롬프트·대결 기록은 유지됩니다.

## 그림체 제작 작업 화면

그림체 설정은 왼쪽의 `작가 조건 / 가중치`에서 바꾸고 접을 수 있습니다.
프롬프트와 생성 장수·랜덤 대상은 오른쪽 한 패널에서 설정합니다.
고정·캐릭터 프롬프트, 생성 파라미터, 공유·태그 조건과 고정 작가는 모달에서 편집합니다.
생성 버튼은 이동·접기·닫기가 가능한 `생성 리모콘`에 있으며 상단에서 다시 열 수 있습니다.
오른쪽 시계 아이콘으로 히스토리를 펼치면 목록 안에서 스크롤할 수 있습니다.
`현재 조합`은 미리보기에서 선택된 작가를 먼저 보여 주며, 고정 후보 전체는 아래에서 펼쳐 편집합니다.
생성 결과의 `조합 보기`는 해당 이미지에 실제 사용된 명단을 표시합니다.
프롬프트 패널의 `제외 N` 탭에서 제외한 태그를 바로 누르거나 `전체 복구`로 한꺼번에 되돌릴 수 있습니다.
가중치 그래프는 20명도 전체 분포를 함께 보여 주며, 선택한 자리의 값을 조절한 뒤 적용합니다.

## NovelAI V5와 V4.5

- 모델에서 `V5 Full Medium`을 선택하면 미디엄 모드로 생성합니다. 14스텝·Euler Ancestral·Karras와 네거티브 프리셋이 고정되고 Rescale·Variety+는 꺼집니다. Prompt Guidance와 베이스·캐릭터 프롬프트는 수정할 수 있습니다. 기존 네거티브 입력은 이 모드에서 적용되지 않으며, 다른 모델로 돌아가면 다시 편집할 수 있습니다. 생성 기록·확정 그림체·비교군에도 Medium 모델을 보존합니다. [NovelAI 공식 안내](https://journal.novelai.net/novelai-diffusion-v5-full-effort-toggle/)
- `nai-diffusion-5-full`, `nai-diffusion-5-curated`, `nai-diffusion-4-5-full`, `nai-diffusion-4-5-curated`를 함께 선택하고 생성할 수 있습니다. 생성 기록·확정 그림체·비교군에도 선택·저장된 모델 정보를 보존합니다.
- V5는 Character Prompt를 최대 22개, V4.5는 최대 6개까지 지원합니다. 모델을 바꿀 때 제한을 넘는 입력을 삭제하거나 잘라내지 않고, 현재 모델에서 생성할 수 없도록 안내합니다.
- V5의 Complexity는 `low complexity`, `medium complexity`, `high complexity`, `ultra complexity` 프롬프트 태그로 선택하며, 선택하지 않으면 자동으로 추가하지 않습니다. 기존 quality prompt·negative prompt·qualityToggle과 NovelAI의 구조화된 캐릭터 프롬프트도 유지합니다.
- PNG·WebP EXIF·NovelAI stealth·raw metadata에서 실제 모델 값을 우선해 V5 Full/Curated, V4.5 Full/Curated를 표시하고 Character Prompt를 복원합니다. 실제 모델을 판별할 수 없는 이미지는 `Unknown`으로 남깁니다.
- 아카라이브 공유 그림체는 게시글이 아니라 이미지 단위의 메타데이터 모델로 `전체`, `V5만`, `V4.5만`, 세부 모델, `Unknown` 필터를 적용할 수 있습니다. V4.5와 V5가 섞인 게시글도 각 이미지가 올바른 결과에 남습니다.
- NovelAI Usage의 사용 가능 여부·퍼센트·다음 변화까지의 시간을 표시하면서 기존 Anlas 표시를 유지합니다. 새 필드가 없는 구독 응답과 기존 사용자 DB도 계속 읽습니다.

## EXE 사용

1. GitHub Releases에서 `DanbooruArtistRater.exe`를 받습니다.
2. EXE를 실행하면 작은 리모콘 창이 열립니다.
3. `서버를 켜면 웹사이트 자동으로 열기`를 체크한 뒤 `서버 켜기`를 누르거나, 서버가 켜진 뒤 `웹사이트 열기`를 누릅니다. 자동 열기 선택은 다음 실행에도 유지됩니다.
4. 리모콘에서 서버를 끄거나 GitHub 최신 릴리스 기준 업데이트를 확인할 수 있습니다. 리모콘의 X 버튼으로 닫아도 실행 중인 서버를 먼저 종료합니다.
5. 설정, DB, 썸네일, 생성 이미지와 로그인 프로필은 EXE 옆 `data` 폴더에 저장됩니다.

아카라이브 성인 게시판 로그인 연결에는 로컬 Chrome이 필요합니다. 화면의 `자동 연결 / 전용 로그인 창`은 Chrome·Edge 쿠키 자동 확인 후 앱 전용 로그인 창으로 이어집니다.

v0.1.14부터는 `공유 그림체 수집 → 🔞 게시판 로그인 → 계정 저장하고 자동 로그인`에서 아이디와 비밀번호를 입력하고 **저장하고 로그인**을 누를 수 있습니다. 확장 프로그램 없이 앱이 관리하는 전용 Chrome 창에서 아이디·비밀번호를 한 번 자동 입력합니다. 캡차나 추가 인증이 나오면 열린 창에서 직접 완료하세요. 다음부터는 **저장된 계정으로 로그인**을 누르면 됩니다. R18 기간 수집은 연결 후 자동으로 이어지며, 링크 추가·조회/추천 갱신은 먼저 로그인을 연결한 뒤 실행하세요.

로그인 정보는 `data/arca_credentials.bin`에 Windows 현재 사용자 암호화로 저장합니다. 비밀번호는 화면이나 API 응답으로 다시 내보내지 않습니다. 다른 PC·Windows 계정으로 옮겼다면 다시 저장해야 합니다. 계정마다 전용 Chrome 프로필을 분리하며 **저장된 계정 삭제**는 저장한 아이디·비밀번호만 지웁니다. 기존 브라우저 로그인 세션은 유지됩니다.

브라우저 로그인 성공과 앱의 게시판 접속 확인은 별도입니다. 인증서 확인 실패는 `ARCA_TLS`, 프록시 연결 실패는 `ARCA_PROXY`로 표시합니다. 실패 제보에는 앱 버전, 누른 버튼, 화면의 오류 문구 전체, 전용 창이 닫힌 시점을 알려 주세요. 아이디·비밀번호·쿠키 파일은 보내지 마세요. 저장 계정 자동 로그인만으로 네트워크 차단 문제가 모두 해결되지는 않습니다.

이미 로그인한 평소 Chrome을 그대로 쓰려면 수집 화면에서 `지금 쓰는 Chrome 로그인 그대로 연결하기`를 펼치고 다음 과정을 처음 한 번만 진행합니다.

1. `설치 폴더 열기`를 누릅니다.
2. Chrome의 `chrome://extensions`에서 개발자 모드를 켜고 `압축해제된 확장 프로그램을 로드`합니다.
3. 열린 `arca_session_bridge` 폴더를 선택한 뒤 확장 버튼의 `현재 로그인 연결`을 누릅니다.

기존 확장 사용자는 앱 업데이트 후 **설치 폴더 열기**를 다시 눌러 확장 파일을 갱신하고,
Chrome의 `chrome://extensions`에서 **Arca Session Bridge 새로고침**을 누른 뒤 **현재 로그인 연결**을 눌러 주세요.
확장 버전은 `1.0.1`입니다. 연결 실패 시 표시되는 구체적인 이유를 확인하고, 앱에서는 **연결 상태 확인**으로 결과를 갱신합니다.

확장은 `arca.live` 쿠키 읽기와 `127.0.0.1` 로컬 앱 연결 권한만 사용합니다. 전달된 Arca 쿠키는 앱 프로세스 메모리에만 있고 응답·로그·설정 파일에는 저장되지 않습니다. NovelAI App Key도 GitHub나 EXE에 포함되지 않으며 사용자 PC의 `data/settings.json`에만 저장됩니다.

그림체 수집은 NovelAI PNG 프롬프트 메타데이터 정리가 목적입니다. 메타데이터를 추출할 수 없는 JPEG·SVG·일부 WebP 샘플 원본은 내려받아 보관하지 않고, 게시글 정보와 재확인 방지 기록만 남깁니다.

배포본에는 빌드 시점의 공유 그림체 게시글·프롬프트·고정 원본 게시글 주소만 기본 데이터로 포함되며 이미지 파일은 포함되지 않습니다. 로컬 이미지가 없는 동안 원본 이미지 URL도 화면에 노출하지 않습니다. `용량·시간 확인`은 로컬 DB와 이미 받은 파일만 사용하므로 즉시 끝나고 사이트를 다시 조회하지 않습니다. `다운로드 시작`을 누르면 아직 유효한 이미지 URL을 우선 사용하고, 만료된 URL만 고정 원본 게시글에서 게시글별로 갱신한 직후 저장합니다. ac.namu.la의 429 제한을 피하도록 요청 시작을 1.1초 간격으로 조절하며, 429와 일시 오류는 같은 작업 안에서 자동 재시도합니다. 중단 후 다시 실행하면 남은 이미지만 이어받습니다.

빠른 설치는 공유 그림체 수집 화면의 `Hugging Face에서 빠르게 받기`를 사용합니다. [공유 그림체 데이터셋](https://huggingface.co/datasets/okawaritsuika/nai-shared-styles)의 WebP 이미지팩을 중단 지점부터 이어받고 SHA-256·파일별 매니페스트·기본 DB 이미지의 포함 여부를 검증한 뒤 `data\arca_style_images`에 안전하게 풉니다. 자동 다운로드가 막히면 같은 배포 ZIP을 브라우저에서 직접 받은 뒤 `내 ZIP 설치`로 선택할 수 있습니다. 기존 아카라이브 직접 다운로드 방식도 그대로 사용할 수 있습니다.

`내 ZIP 설치`는 현재 WebP 팩과 예전 `NAImakeArtistGroup_shared_images_v0.1.0.zip` PNG 팩을 용량·SHA-256으로 자동 구분합니다. 파일 이름을 바꿀 필요는 없습니다. 예전 팩은 당시 공개 배포 이미지의 연결 정보로 현재 기본 DB에 있는 이미지만 복원하며, 이후 추가된 이미지는 별도로 받아야 합니다. 연결되지 않은 이미지와 누락 개수를 안내하고 이 경우 업로드한 ZIP 복사본도 보존합니다. 기존 정상 PNG·WebP는 재사용하며 설치 과정에서 재압축하지 않습니다.

배포용 WebP는 품질 90으로 압축하며 해상도를 유지합니다. 프롬프트·네거티브·캐릭터 프롬프트·원본 생성 설정 JSON은 EXIF UserComment에 보존하고, 변환 전후 전체 메타데이터가 일치하는 파일만 포함합니다. 사용자의 원본 파일은 변환하거나 삭제하지 않습니다. 이미지팩에 기본 DB의 이미지가 빠져 있거나 설치 후 파일이 없으면 누락을 안내합니다.

공유 그림체 통계는 V4.5 / V5 / 전체 탭으로 전환하며 기본은 V5입니다. 기존 data 폴더로 업데이트하면 새 기본 데이터만 병합합니다. 이미지팩 ZIP은 한 번 받되, 설치 시 기존 정상 PNG·WebP를 재사용하고 없는 이미지만 추가합니다.

ZIP 이미지는 사용자 DB의 변동 가능한 내부 행 번호가 아니라 게시글 주소와 안정 이미지 주소로 연결됩니다. 이미지가 모두 준비되면 두 다운로드 방식은 접힌 `공유 그림체 이미지 설치·복원` 영역 안에 최소화되며 필요할 때 다시 열 수 있습니다.

수집 조건의 `WebP 압축`을 체크하면 새 PNG를 품질 90 WebP로 저장합니다. 프롬프트·생성 설정 보존 검증에 실패하면 원본을 저장하며, 기존 파일과 WebP는 재압축하지 않습니다. 검색 수집과 링크 추가에 적용되고 중단 후 재개할 때도 유지됩니다.

당일 수집한 날짜는 새 글이 추가될 수 있으므로 다시 검색합니다. 다음 날에도
전날을 수집 기간에 포함하면 첫 수집 이후 올라온 글을 확인하며, 이미 받은 정상 이미지는 재사용합니다.
`조회·추천 갱신`을 누르면 갱신할 모델을 선택하는 창이 열립니다. 기본값은 V5이며,
전체·V4.5·세부 모델·Unknown도 선택할 수 있습니다. 선택 모델 이미지가 한 장이라도
있는 저장 게시글을 대상으로 하며, 화면의 날짜·목록 필터와는 별도입니다.
수집 당시 사용한 검색어의 제목 검색 목록에서 여러 글의 숫자를 함께 갱신하고,
목록에서 못 찾은 글만 개별 게시글을 확인합니다. 기존 검색어가 더 넓은 범위인 경우
중복 검색을 줄이며, 추천수 하한으로 갱신 대상이 빠지지 않도록 합니다.
이미지를 내려받거나 저장된 프롬프트·메모를 바꾸지 않습니다. 목록 페이지 수·진행 수·
갱신 수·미확인 수와 개별 확인 단계를 표시하며, 삭제·접근 불가 등으로 숫자를 확인하지
못한 글은 기존 값을 유지합니다. 선택 대상에 R18 게시글이 있으면 Chrome 로그인 연결이
필요합니다. 일시정지 후 계속할 수 있으며, 중지·앱 종료 후 다시 시작할 때도 선택 모델을
유지합니다. 요청 제한·계속되는 연결 오류가 발생하면 갱신한 값을 보존하고 중단합니다.
걸리는 시간은 검색 목록 페이지 수·개별 확인할 글 수·사이트 응답 속도에 따라 달라집니다.

## 소스 실행

```powershell
cd artist_rater
python -m pip install -r requirements.txt
python launcher.py
```

런처 창의 `데이터 폴더` 섹션에서 `폴더 추가`로 여러 폴더를 선택할 수
있습니다. 목록에서 폴더를 선택한 뒤 `선택을 기준으로`를 누르면 설정·저장
기준(primary)이 바뀌고, 서버 실행 중에는 이 구성을 변경할 수 없습니다.
폴더 추가·제거·기준 변경은 기본 `data` 폴더의 `launcher_settings.json`에
저장되어 다음 실행에도 복원되며, 섹션은 기본으로 접혀 있습니다.
프로젝트 루트, `artist_rater` 폴더 또는 실제 `data` 폴더를 선택하면 내부의
`artist_rater.sqlite` 위치를 자동으로 찾습니다.

로컬 테스트에서 여러 `data` 폴더를 함께 보려면 `--data-dir`를 반복하고,
쓰기·설정 기준 폴더를 `--primary-data-dir`로 지정합니다. primary는 첫 번째
폴더로 기본 선택되며, 보조 폴더의 DB·이미지는 중복 제거 후 primary에 읽기
전용 원본을 보존한 채 병합됩니다.

```powershell
python launcher.py --data-dir C:\work\data-a --data-dir C:\work\data-b --primary-data-dir C:\work\data-b
```

## 외부 주입 API

서버가 실행 중인 같은 PC의 프로그램은 `POST /api/external-injection`으로
작가 이름과 PNG 그림 한 장을 외부 주입 테스트 그룹에 추가할 수 있습니다.
그룹은 처음 호출할 때 자동으로 만들어지고, 이후 호출에서는 같은 그룹에
이미지가 누적됩니다.

```powershell
curl.exe -X POST http://127.0.0.1:5001/api/external-injection `
  -F "artist_name=example_artist" `
  -F "image=@C:\images\example.png"
```

요청 필드는 `artist_name`(1~200자)과 `image`(PNG 파일)입니다. 업로드 크기는
32MB 이하이고 가로·세로는 각각 2048픽셀 이하이어야 합니다. JPEG·WebP와
파일 경로·URL 입력은 지원하지 않습니다. 응답의 `test_id`, `item_id`,
`generated_image_id`, `image_url`로 추가된 테스트와 이미지를 확인할 수
있으며, 기존 NAI 작가 테스트의 상세·이력·평가 API를 그대로 사용할 수
있습니다. 이 엔드포인트는 `127.0.0.1` 또는 `::1`에서만 요청할 수 있습니다.

## EXE 빌드

```powershell
python -m pip install pyinstaller
.\build_exe.ps1
```

빌드 결과는 `release/DanbooruArtistRater.exe`에 생성됩니다. App Key·개인 작가 평가(ratings)·로컬 설정·생성 이미지·로그인 정보는 포함되지 않습니다. 공유 그림체 메타데이터와 공개 Danbooru 작가 수 캐시만 로컬 이미지 경로를 제거한 전용 시드 DB로 포함됩니다. EXE는 콘솔 창 없이 리모콘만 표시합니다.

빌드는 저장소의 검증된 시드와 이미지팩의 SHA-256 연결을 확인합니다. 로컬 사용자 DB를 자동으로 다시 내보내지 않습니다. 새 데이터 배포 과정은 [공유 이미지팩 배포](docs/shared_image_release.md)를 참고하세요.
