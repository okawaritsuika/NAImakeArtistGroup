# v0.1.4 — 확정 그림체와 비교군 관리

## 주요 변경

- 그림체 관리를 제작 기록·확정 그림체·공유 그림체로 분리하고 검색, 필터, 페이지당 표시 수, 카드 크기 조절을 추가했습니다.
- 제작 기록과 공유 그림체를 프롬프트 및 NovelAI 생성 설정을 확인·수정한 뒤 확정 그림체로 저장할 수 있습니다.
- 이미지 붙여 넣기와 드래그로 확정 그림체를 직접 추가하고, 읽지 못한 메타데이터는 수동 입력할 수 있습니다.
- 확정 그림체 여러 개로 같은 조건의 이미지를 생성하는 비교군 관리를 추가했습니다.
- 비교군을 폴더형 갤러리로 열어 결과와 상세 정보를 확인하고, 개별 이미지를 삭제하거나 재습득할 수 있습니다.
- 비교 이미지가 완성될 때마다 `완료 수 / 전체 수` 진행 상황을 표시합니다.
- 숫자로 끝나는 태그가 `태그 ::` 형식을 사용하도록 가져오기·저장·생성 전 과정에서 자동 보정합니다.
- NovelAI V4/V4.5 요청 형식과 저장된 모델·샘플러·스케줄러·Steps·CFG·Rescale·Variety+ 전달을 정리했습니다.
- 캐릭터 프롬프트 여러 개 추가·삭제, 공통 시드 3가지 방식, NovelAI 오류 요청 ID 표시를 지원합니다.
