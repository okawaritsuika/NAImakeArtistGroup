진짜 급한 사람을 위한 7줄 요약

  1. EXE를 실행하고 리모콘에서 서버를 켭니다.
  2. 설정에서 NovelAI App Key를 저장하고 연결 테스트를 합니다.
  3. 그림체 제작에서 작가 수를 7명으로 설정합니다.
  4. 평가한 작가가 없으면 공유 7~7, 있으면 공유 4~5와 원하는 평점을 선택합니다.
  5. 전체 ↻를 눌러 작가와 가중치를 뽑습니다.
  6. 캐릭터 프롬프트를 입력하고 1장 생성을 누릅니다.
  7. 마음에 드는 결과가 나오면 작가는 유지한 채 가중치만 바꿔 좁혀 갑니다.

5. 작가 7명으로 첫 그림체 만들기

처음 시작할 때는 전체 작가 수를 7명으로 둡니다. 아직 평가한 작가가 없다면 공유 그림체 작가만 사용하고, 마음에 드는 작가를 이미 평가했다면 공유 작가에 개인 평가 작가 몇 명을 섞습니다.

항목A. 공유 그림체만B. 평가한 작가 섞기
작가 수77
공유 작가 최소 / 최대7 / 74 / 5
허용 평점전체 선택섞고 싶은 평점 선택
예: 마음에 든 작가를 4·5점으로 평가했다면 4·5 선택
가중치 방식균형균형
가중치 최소 / 최대0.1 / 2.30.1 / 2.3

A는 공유 작가 7명만 뽑는 가장 간단한 시작법입니다. B는 공유 작가 4~5명과 개인 평가 작가 2~3명을 섞는 방법입니다. 전체 ↻를 누를 때 선택한 허용 평점 안에서 개인 작가가 나머지 자리를 채웁니다.

B를 안정적으로 사용하려면 선택한 평점에 해당하는 개인 평가 작가가 최소 3명은 있어야 합니다. 해당 작가가 2명뿐이면 공유 최소·최대를 5 / 5로, 1명뿐이면 6 / 6으로 맞추세요. 아직 평가 자료가 없다면 A로 시작한 뒤, 작가 뽑기에서 마음에 드는 작가를 평가하고 B로 넘어가면 됩니다.

12명은 특징이 많이 겹치거나 흐려질 수 있으므로 이 글에서는 7명을 시작값으로 사용합니다. 입력이 끝나면 가운데 위쪽의 전체 ↻를 눌러 작가 7명과 가중치를 뽑습니다.

8. 세 가지 다시 뽑기 버튼의 차이

  • 작가 ↻: 고정하지 않은 작가를 새로 뽑고 현재 가중치 흐름은 유지합니다.
  • 가중치 ↻: 현재 작가들은 유지하고 가중치만 다시 뽑습니다.
  • 전체 ↻: 작가와 가중치를 모두 새로 뽑습니다.

완전히 새로운 후보를 찾을 때는 전체, 작가 조합은 마음에 드는데 느낌이 애매할 때는 가중치, 가중치 흐름은 괜찮지만 작가들이 마음에 안 들 때는 작가 버튼을 사용합니다.

9. 공정하게 비교하는 방법

그림체를 조절할 때 가장 흔한 실수는 여러 조건을 한꺼번에 바꾸는 것입니다. 무엇 때문에 결과가 달라졌는지 알 수 없게 됩니다.

  1. 마음에 드는 결과의 시드를 확인합니다.
  2. 생성 설정의 시드 칸에 넣고 고정을 체크합니다.
  3. 캐릭터·퀄리티·고정·네거티브 프롬프트와 해상도를 그대로 둡니다.
  4. 작가, 가중치, 순서 중 하나만 바꿉니다.
  5. 2~4장을 생성해 비교한 뒤 더 나은 방향만 남깁니다.

시드 고정은 그림을 완전히 같게 만드는 기능이 아니라 비교 조건을 최대한 비슷하게 만드는 기능이라고 생각하면 됩니다.

10. 작가 순서와 가중치 직접 조절

  • 가중치 표에서 숫자를 직접 바꿀 수 있습니다.
  • 자리별 가중치 그래프를 열어 각 자리의 가중치 흐름을 조절할 수 있습니다.
  • 고정 작가를 원하는 위치에 추가하고 다른 자리로 이동할 수 있습니다.
  • 가중치 오름차순·내림차순 정렬로 빠르게 순서를 바꿀 수 있습니다.

한 작가의 특징이 지나치게 강하면 그 작가의 가중치를 낮추고, 원하는 특징이 거의 보이지 않으면 조금씩 높입니다. 0.1에서 2.3 끝까지 한 번에 움직이기보다 0.1~0.3씩 바꿔 비교하는 편이 원인을 찾기 쉽습니다.

고정 작가도 전체 작가 수에 포함됩니다. 예를 들어 작가 수가 7명이고 고정 작가가 5명이면 다시 뽑는 자리는 2개입니다. 이때 공유 작가 최소·최대를 2/2로 두면 두 자리 모두 공유 그림체에서 뽑고, 0/0으로 두면 허용 평점과 평가 작가 태그 필터에 맞는 개인 평가 작가 중에서 두 명을 뽑습니다.

11. 실제 그림체 탐색 3단계

1단계 · 넓게 찾기

작가 수 7명과 균형 가중치로 전체를 여러 번 다시 뽑습니다. 처음에는 공유 작가 7명만 사용해도 되고, 평가한 작가가 있다면 공유 작가 4~5명과 개인 평가 작가 2~3명을 섞어도 됩니다. 이때는 세부 오류보다 전체 색감, 선, 얼굴, 채색 분위기가 마음에 드는지 봅니다.

2단계 · 작가를 유지하고 가중치 찾기

마음에 드는 결과가 나오면 작가는 유지합니다. 같은 시드에서 가중치만 다시 뽑아 어떤 분배가 가장 안정적인지 찾습니다.

3단계 · 수동 미세 조정

너무 강한 작가를 낮추고, 필요한 작가를 직접 추가하거나 순서를 옮깁니다. 이 단계부터는 매번 변경한 내용을 메모하면 되돌아가기 쉽습니다.

전체 탐색 → 마음에 드는 작가 조합 발견 → 작가 유지 → 가중치 탐색 → 수동 조정 → 다른 구도로 검증

12. 연속 생성으로 후보를 빠르게 찾기

  1. 처음에는 생성 장수를 10~20장 정도로 둡니다.
  2. 넓게 찾을 때는 매 장 랜덤 변경에서 작가와 가중치를 켭니다.
  3. 퀄리티와 네거티브까지 동시에 바꾸면 비교 변수가 많아지므로 처음에는 끄는 편이 쉽습니다.
  4. 연속 생성을 시작하고 결과를 관찰합니다.
  5. 마음에 드는 작가 조합을 발견하면 일시정지하고 그 조합을 확인합니다.
  6. 다음 탐색에서는 작가는 끄고 가중치만 켜서 범위를 좁힙니다.
비용 주의: 무제한 생성은 중지할 때까지 계속될 수 있습니다. 처음에는 지정 장수를 사용하고 생성 상태를 확인하세요.

13. 그림체 관리에서 비교하고 보관하기

생성에 성공한 이미지는 별도 저장 버튼을 누르지 않아도 자동 저장됩니다. 그림체 관리에서는 다음 정보를 다시 확인할 수 있습니다.

  • 작가 조합과 순서
  • 각 작가의 가중치
  • 퀄리티·고정 태그가 합쳐진 기본 프롬프트
  • 네거티브와 캐릭터 프롬프트
  • 시드, 해상도, Sampler, Steps, CFG 등 생성 설정

한 캐릭터 얼굴만 잘 나온 조합을 바로 확정하지 말고, 얼굴 중심·상반신·전신 또는 배경 포함 장면으로 다시 생성해 그림체가 유지되는지 확인합니다.

14. with 다키마쿠라 · 전신 제작에 쓸 상반신 원본 만들기

여기서 다키마쿠라 태그를 쓰는 목적은 단순히 그림체를 비교하는 데서 끝나지 않습니다. 먼저 얼굴, 머리카락, 피부와 옷의 디테일이 좋은 고품질 상반신 원본을 만들고, 이후 긴 전신 그림으로 확장할 때 기준 이미지로 사용하기 위해서입니다. 다키마쿠라는 실제로 상반신을 가장 자주 보게 되므로 이 첫 원본의 완성도가 중요합니다.

이 프로그램이 맡는 범위

이 글에서는 다키마쿠라에 어울리는 작가 조합을 찾고, 상반신 원본을 생성해 고르는 단계까지 설명합니다. 원본을 긴 캔버스로 확장하고 하반신을 인페인팅한 뒤 2500×8000, 5000×16000 등으로 업스케일·보정하는 작업은 별도의 이미지 편집 도구가 필요한 다음 단계입니다.

14-1. 다키마쿠라 관련 작가 후보 찾기

  1. 작가 뽑기 화면으로 이동합니다.
  2. 태그/프롬프트 검색에 dakimakura_(medium)을 입력합니다.
  3. 후보 작가 수와 샘플 수를 정하고 작가 후보를 뽑습니다.
  4. 샘플을 보면서 원하는 선, 얼굴, 채색과 가까운 작가에게 점수를 줍니다.
  5. 한 명만 고르기보다 마음에 드는 작가를 여럿 평가하고, 공유 작가와 함께 전체 7명 조합에 일부 섞어 봅니다.

14-2. 상반신 원본용 프롬프트 만들기

그림체 제작에서 방금 평가한 작가를 사용하거나 고정 작가로 추가합니다. 자신이 만들 캐릭터의 이름·외형·복장을 캐릭터 프롬프트에 넣고, 다키마쿠라 조건과 상반신 구도는 고정 태그에 넣습니다.

입력칸예시
캐릭터 프롬프트1girl, solo, 캐릭터 이름, 머리색, 눈색, 원하는 복장, looking at viewer
고정 태그 · 다키 조건3::dakimakura (medium), white sheet, lying::
고정 태그 · 구도3::bust shot:: 또는 close-up, upper body
퀄리티·네거티브처음에는 자동 추천 유지

bust shot, close-up, upper body는 얼굴과 상체가 화면에서 충분히 크게 나오도록 돕습니다. 긴 전신을 처음부터 한 번에 뽑는 것보다 상반신을 먼저 크게 생성해야 얼굴과 머리카락, 옷의 세부 묘사를 확보하기 쉽습니다.

3::dakimakura (medium), white sheet, lying::는 다키마쿠라 매체, 흰 시트, 누운 자세를 한 묶음으로 강조하는 시작값입니다. 결과에서 다키마쿠라 느낌이 지나치게 강하거나 약하면 숫자를 조금씩 바꿔 비교하세요. 작가 검색에 쓰는 Danbooru 태그 dakimakura_(medium)과 NovelAI 프롬프트 표기는 다르므로 구분해야 합니다.

white sheet는 복잡한 배경을 줄이고 흰 시트 위에 누운 구도를 유도합니다. 캐릭터 외형과 작가 조합을 비교할 때 배경의 영향을 줄이는 데도 도움이 됩니다.

14-3. 1024×1024로 후보를 뽑고 고해상도로 다시 만들기

  1. 해상도를 1024×1024로 두고 같은 캐릭터와 그림체로 여러 장 생성합니다.
  2. 얼굴, 머리카락, 손, 피부, 옷 주름이 선명하고 캐릭터 특징이 잘 유지된 결과를 고릅니다.
  3. 마음에 드는 결과의 프롬프트와 그림체를 유지한 채 사용자 지정 해상도 1600×1536 또는 1600×1472로 다시 생성합니다.
  4. 고해상도 결과에서도 얼굴과 상반신이 무너지지 않았는지 확인하고, 가장 좋은 한 장을 이후 전신 확장 작업의 원본으로 저장합니다.

무작정 생성 장수를 크게 잡으면 Anlas가 많이 들 수 있습니다. 처음에는 1장 생성으로 구도와 태그가 맞는지 확인한 뒤, 필요한 만큼만 연속 생성하세요. 고해상도 재생성은 선택한 후보에만 하는 편이 효율적입니다.

15. 결과가 이상할 때 빠른 해결표

문제먼저 할 일
그림이 너무 뒤섞여 보임작가 수를 줄이거나 영향이 강한 작가 가중치를 낮춤
한 작가 느낌만 지나치게 강함해당 작가 가중치를 0.1~0.3씩 낮추며 비교
작가를 바꿔도 차이가 작음시드를 고정하고 작가·가중치 외 조건이 바뀌지 않았는지 확인
캐릭터가 자꾸 달라짐캐릭터 프롬프트를 고정하고 외형 태그를 구체화
가로와 세로에서 느낌이 다름이상 현상이 아니라 구도 영향일 수 있으므로 두 비율에서 각각 검증
자동완성이 안 뜸텍스트 편집인지, 두 글자 이상인지, 인터넷 연결이 되는지 확인
생성이 안 됨App Key 연결 테스트, 구독 상태, 오류 문구를 순서대로 확인

16. 처음 사용하는 사람용 최종 확인표

  • 서버를 켜고 웹사이트를 열었는가?
  • NovelAI App Key 연결 테스트가 성공했는가?
  • 작가 수를 7명으로 두고, 공유 7/7 또는 공유 4/5와 개인 평가 작가 혼합 중 하나를 선택했는가?
  • 캐릭터 태그는 캐릭터 프롬프트에 넣었는가?
  • 계속 유지할 구도·배경 태그는 고정 태그에 넣었는가?
  • 비교할 때 시드와 나머지 프롬프트를 고정했는가?
