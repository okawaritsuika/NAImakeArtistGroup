# 그림체 생성 및 관리 설계

## 목표

기존 작가 평가 데이터를 이용해 여러 작가를 순서와 가중치가 있는 NovelAI 그림체 프롬프트로 조합하고, 실제 이미지를 한 장 또는 연속으로 생성한다. 생성 성공 직후 결과 이미지와 사용 정보를 자동 저장하며, 저장된 결과는 그림체 관리 화면에서 조합별로 확인한다.

## 화면 구조

기존 `작가 뽑기`, `평가 관리`에 다음 화면을 추가한다.

- `그림체 제작`: 작가 추출, 가중치 편집, 프롬프트 입력, NovelAI 생성 설정, 연속 생성 제어, 최신 결과 미리보기
- `그림체 관리`: 그림체 조합 목록, 조합별 생성 이미지, 이미지별 프롬프트와 생성 설정 확인
- 공통 `설정` 버튼과 모달: NovelAI App Key 저장, 연결 테스트, 삭제

전체 화면은 브라우저 자체의 세로 스크롤을 최소화하고, 필요한 패널 내부만 스크롤한다. 그림체 제작에서는 설정 영역을 접거나 닫아 결과 영역을 넓힐 수 있게 한다.

## 작가 선택

- 기본 작가 수는 12명이며 사용자가 변경할 수 있다.
- 평가 점수 1~5는 직관적인 다중 선택 버튼으로 제공하며 전체 선택과 전체 해제를 지원한다.
- 점수는 작가 추출 확률에 영향을 준다. 5점은 매우 높음, 4점은 높음, 3점은 보통, 2점은 낮음, 1점은 매우 낮음으로 취급한다.
- 1~2점 작가도 선택 점수에 포함되어 있다면 완전히 배제하지 않는다.
- 이미 선택된 작가를 같은 조합 안에서 중복 추출하지 않는다.
- 작가만 다시 추출, 가중치만 다시 추출, 작가와 가중치 모두 다시 추출을 지원한다.

## 가중치 모드

최소·최대 가중치의 기본값은 0.1과 2.3이며 소수 입력을 지원한다.

### 완전 랜덤

각 작가의 가중치를 지정 범위 안에서 독립적으로 추출한다. 평점 우선 옵션을 켜면 높은 평점이 높은 가중치를 받을 확률만 높아지며 결과를 강제하지 않는다.

### 적당히 랜덤

높은 가중치가 지나치게 많아지지 않도록 인원 구간을 제한한다. 12명 기준 기본 배분은 다음과 같다.

- 낮음 0.1~0.9: 5명
- 중간 1.0~1.49: 4명
- 높음 1.5~2.3: 최대 3명

다른 인원수에는 약 42%, 33%, 25% 비율을 적용하고 높은 구간은 전체의 25%를 넘기지 않는다. 반올림 차이는 낮은 구간부터 보정한다. 평점 우선 옵션을 켜면 4~5점 작가가 높은 구간을 받을 가능성이 커지고 1~2점 작가는 주로 낮은 구간을 받지만, 드물게 높은 구간도 받을 수 있다.

### 직접 지정

사용자가 `최소, 최대, 최대 인원`으로 구성된 구간을 자유롭게 추가·삭제한다. 구간 총 수용 인원이 작가 수보다 적으면 생성 전에 오류를 표시한다. 직접 지정 구간이 하나도 없으면 완전 랜덤 방식으로 처리한다.

## 가중치 그래프와 순서

그래프의 왼쪽에서 오른쪽 순서가 최종 작가 프롬프트 순서다. 기본 정렬은 낮은 가중치에서 높은 가중치 순이다.

- 막대 끌기로 작가 순서 변경
- 막대 높이 끌기와 숫자 입력으로 가중치 변경
- 두 작가 위치 교환
- 작가 추가와 삭제
- 가중치 오름차순과 내림차순 정렬
- 가중치만, 작가만, 전체 다시 추출

최종 작가 프롬프트는 그래프 순서대로 `1.35::artist_name::` 항목을 쉼표로 연결한다.

## 생성 프롬프트

생성 화면은 다음 입력을 제공한다.

- 기본 프롬프트
- 네거티브 프롬프트
- 여러 개를 추가·삭제할 수 있는 캐릭터 프롬프트

NovelAI의 최종 기본 캡션은 사용자 기본 프롬프트와 작가 프롬프트를 결합한다. 작가 프롬프트는 별도 구조로도 보존하여 그림체 식별과 관리에 사용한다. 네거티브 프롬프트는 V4 네거티브 캡션과 일반 네거티브 필드에 전달한다. 각 캐릭터 프롬프트는 NovelAI V4.5의 개별 `char_caption`으로 전달하며 기본 위치는 중앙이다.

## NovelAI 생성 설정

참고 앱의 V4.5 Full 생성 요청 구조를 따른다.

- 모델: `nai-diffusion-4-5-full`
- 해상도: 너비와 높이, 64 단위 검증
- Sampler
- Steps
- CFG Scale
- CFG Rescale
- Seed: 생성마다 무작위 생성하고 실제 사용값 저장
- 요청당 결과 수: 1장

서버는 `https://image.novelai.net/ai/generate-image`에 Bearer 인증으로 요청하고 ZIP 응답에서 PNG를 추출한다. App Key는 서버에 저장된 설정에서 읽으며 브라우저의 생성 요청이나 결과 메타데이터에 다시 포함하지 않는다.

## App Key 설정

상단 설정 버튼으로 모달을 연다.

- 마스킹된 App Key 입력
- 연결 테스트: NovelAI 구독 API를 호출해 인증 성공 여부와 가능하면 Anlas를 표시
- JSON 저장
- 저장된 키 삭제

키는 `artist_rater/data/settings.json`에 저장한다. 서버 API는 키의 존재 여부만 반환하며 실제 키 문자열은 클라이언트에 돌려주지 않는다. 이 파일은 로컬 비밀 정보이므로 Git 추적 대상에서 제외한다.

## 단일 및 연속 생성

생성은 브라우저 반복 호출 방식으로 동작한다. 브라우저가 한 장 생성 요청을 보내고 성공 또는 실패 처리를 마친 뒤 다음 요청을 보낸다.

실행 방식은 다음 두 가지다.

- 지정 장수: 사용자가 입력한 장수에 도달하면 종료
- 계속 생성: 중지할 때까지 반복

각 방식에서 그림체 변경 규칙을 선택한다.

- 가중치만 변경: 작가와 순서는 유지하고 매 생성 전에 가중치를 다시 추출
- 작가·가중치 모두 변경: 매 생성 전에 작가, 순서, 가중치를 모두 다시 추출

일시정지는 현재 요청이 끝난 뒤 다음 요청 전 적용한다. 중지도 현재 요청을 강제 취소하지 않고 완료 후 반복을 종료한다. 새로고침이나 탭 종료 시 반복 상태는 복구하지 않는다.

## 자동 저장과 그림체 식별

NovelAI 생성이 성공하면 서버가 PNG와 이미지별 메타데이터를 즉시 저장한다. 사용자가 별도 저장 버튼을 누를 필요가 없다.

그림체 식별에는 다음 값만 사용한다.

- 작가 태그
- 작가 순서
- 각 작가의 정확한 가중치

동일 작가와 동일 가중치라도 순서가 다르면 다른 그림체다. 기본, 네거티브, 캐릭터 프롬프트와 생성 설정은 그림체 식별에는 사용하지 않지만 각 이미지 기록에 저장한다.

서버는 정규화된 작가 배열을 안정적인 JSON으로 직렬화하고 해시를 만들어 그림체 키로 사용한다. 같은 키가 있으면 기존 그림체에 이미지를 추가하고, 없으면 새 그림체 레코드를 만든다.

## 저장 구조

SQLite에 다음 정보를 저장한다.

### `art_styles`

- 식별자와 그림체 해시
- 순서가 보존된 작가·가중치 JSON
- 표시용 작가 프롬프트
- 대표 이미지 경로
- 생성 이미지 수
- 최초·최종 생성 시각

### `generated_images`

- 소속 그림체 식별자
- PNG 경로
- 기본 프롬프트
- 네거티브 프롬프트
- 캐릭터 프롬프트 배열
- 결합된 실제 기본 캡션
- 작가 프롬프트와 작가·가중치 배열
- Seed, 너비, 높이, Sampler, Steps, CFG Scale, CFG Rescale, 모델
- 생성 시각

App Key는 어느 테이블과 이미지 메타데이터에도 저장하지 않는다. PNG는 `artist_rater/data/generated/<style-id>/` 아래에 보관한다.

## 그림체 관리

그림체 목록은 대표 이미지, 작가 수, 생성 이미지 수, 최근 생성 시각을 보여준다. 항목을 열면 다음을 확인한다.

- 순서가 보존된 작가와 가중치
- 작가 프롬프트
- 해당 그림체로 생성된 이미지 목록
- 선택 이미지의 기본, 네거티브, 캐릭터 프롬프트
- Seed와 NovelAI 생성 설정

이미지를 크게 보는 모달과 이전·다음 탐색을 지원한다. 그림체 식별과 이미지별 프롬프트 정보가 섞이지 않도록 구분해서 표시한다.

## API 경계

- 설정 조회, 저장, 삭제, 연결 테스트
- 한 장 생성 및 자동 저장
- 그림체 목록과 상세 조회
- 그림체별 이미지 조회
- 필요 시 생성 이미지 또는 그림체 삭제

한 장 생성 API는 브라우저 반복 로직과 무관하게 독립적으로 동작한다. 서버는 요청 검증, NovelAI 호출, 이미지 추출, 그림체 식별, 파일 및 DB 저장을 하나의 처리 흐름으로 수행하고 저장된 결과 요약을 반환한다.

## 오류 처리

- 키 누락과 인증 실패는 생성 전에 명확히 표시한다.
- NovelAI HTTP 오류 본문은 민감 정보 없이 상태 코드와 메시지로 반환한다.
- 해상도, 장수, 가중치 구간과 프롬프트 입력을 클라이언트와 서버 양쪽에서 검증한다.
- 연속 생성 중 한 장이 실패하면 자동으로 무한 재시도하지 않는다. 오류를 표시하고 반복을 일시정지하여 사용자가 재개 또는 중지한다.
- PNG 저장이나 DB 저장이 실패하면 성공으로 표시하지 않는다. 부분 저장 파일은 정리한다.
- 중복 요청으로 같은 결과가 두 번 저장되지 않도록 생성 요청 식별자를 사용한다.

## 테스트

- 가중치 세 모드의 범위, 구간 인원, 평점 편향과 중복 방지 단위 테스트
- 작가 순서와 가중치 변화에 따른 그림체 해시 동일성·차이 테스트
- 기본·네거티브·캐릭터 프롬프트가 그림체 해시에 영향을 주지 않는 테스트
- App Key가 API 응답, DB, 이미지 메타데이터에 포함되지 않는 테스트
- NovelAI ZIP 응답을 모의한 생성·자동 저장 API 테스트
- 지정 장수, 계속 생성, 일시정지, 중지와 두 변경 규칙의 프런트엔드 계약 테스트
- 그림체 관리 목록·상세·이미지 탐색 테스트

## 범위 제외

- 서버 백그라운드 작업 큐와 브라우저 종료 후 작업 복구
- 여러 생성 요청의 병렬 실행
- 이미지 편집, 인페인팅, 업스케일
- 클라우드 동기화와 사용자 계정
