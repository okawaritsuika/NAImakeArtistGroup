# Arca Prompt Visual Unification Design

## Goal

Make the collected-style dialog feel like one coherent interface without changing prompt grouping or archive behavior.

## Design

- Use one dark card surface, border color, radius, and spacing scale across style groups and editing controls.
- Present base, negative, and character selectors as one consistent segmented control.
- Keep tag chips the same size and shape; distinguish prompt types with restrained blue, red, and violet tints.
- Place common tags in the primary area and image-specific differences in a quieter inset area.
- Move raw prompts and direct item editing into a clearly labeled secondary section.
- Align close, delete, and save controls and give them consistent heights and states.
- Preserve safe DOM rendering, keyboard-accessible tabs, existing copy/edit/delete behavior, and responsive scrolling.

## Scope

Only the archive dialog markup generated by `arca_style_collector.js` and its CSS are changed. APIs, collection, metadata extraction, grouping, and persistence remain unchanged.

## Verification

Frontend behavior tests verify tab labels and safe rendering. Contract tests verify the unified component classes. Existing Python and JavaScript suites must remain green.
