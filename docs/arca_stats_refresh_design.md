# 조회·추천 갱신 모델 선택

갱신 버튼은 모델 선택 창을 연다. 첫 선택은 V5이며 같은 화면 세션에서는 마지막 선택을 유지한다. 전체·V5·V4.5·각 세부 모델·Unknown은 기존 공유 그림체 모델 필터와 같은 값과 이미지 단위 판별을 쓴다. 선택 모델 이미지가 한 장이라도 있는 저장 게시글을 한 번만 갱신한다.

## 화면 구조

- `arcaStatsRefreshModal`: 기존 `modal`, `modal-backdrop` 재사용. `role=dialog`, `aria-modal=true`, 제목 연결.
- `arca-stats-refresh-dialog`: 최대 너비 480px, 최대 높이 `min(640px, calc(100dvh - 32px))`. 행은 `auto minmax(0, 1fr) auto`로 제목·본문·액션을 분리한다.
- 제목: 조회·추천 갱신, 닫기 버튼. 본문: 대상 안내, `arcaStatsRefreshModel` 선택, 검색 목록 후 남은 글 개별 확인 안내, `arcaStatsRefreshStatus` 오류 표시.
- 하단: `cancelArcaStatsRefresh` 취소, `startArcaStatsRefresh` 갱신 시작. 하단은 스크롤 영역 밖이며 본문만 `overflow-y:auto`이다.
- 320·390px 화면은 바깥 간격 16px 이하, 버튼 높이 44px 이상, 가로 스크롤 없음. 자식은 `min-width:0`, 스크롤 본문은 `min-height:0`을 둔다.

## 상태와 조작

열기만으로 요청하지 않는다. 갱신 시작은 `/api/arca-styles/refresh-stats`에 `{model: 선택값}`을 보낸다. 요청 중 중복 실행과 닫기를 막고, 성공하면 창을 닫고 기존 진행 표시를 사용한다. 실패하면 창 안에 오류를 표시하며 선택값을 유지하고 다시 실행할 수 있다.

Escape·배경·닫기·취소는 요청 전 창을 닫는다. 열릴 때 모델 선택으로 포커스를 옮기고 Tab 이동은 창 안에 머문다. 취소로 닫으면 갱신 버튼으로 포커스를 돌린다. 성공하면 비활성화된 갱신 버튼 대신 진행 패널로 포커스를 옮기며, 작업 종료 시 아직 진행 패널에 포커스가 있는 경우만 갱신 버튼으로 복귀한다. 시작 후 진행 표시는 검색 목록과 개별 확인 단계를 구분한다.

## 검증

Node 행동 테스트로 열기/취소의 요청 없음, 선택 모델 전송, 기본값·선택 유지, 실패 후 재시도, 중복 시작 차단, 키보드·포커스를 확인한다. Python 계약 테스트로 DOM·grid 행·스크롤 경계를 확인한다. 실제 렌더는 1280·901·900·390·320px 및 낮은 화면에서 기본/오류/요청중 상태의 버튼 노출·가림·overflow를 확인한다. 실제 DB와 네트워크 없이 임시 데이터로 검증한다.
