# v0.1.5 — 그림체 제작과 다중 이미지 가져오기 개선

## 주요 변경

- 후보 수집에 제외 프롬프트와 최신 이미지 우선 옵션을 추가했습니다.
- 작가 가중치 표를 큰 모달에서 편집하고, 작가 위치 0의 무작위 순서와 개별 가중치 랜덤을 지원합니다.
- 수집 그림체 프롬프트를 이미지 갤러리에서 확인·수정·즉시 적용할 수 있습니다. 수정한 퀄리티 프롬프트는 다음 실행에도 유지됩니다.
- 여러 이미지와 폴더를 한 번에 가져와 작가 프롬프트가 같은 이미지끼리 확정 그림체 묶음으로 저장합니다.
- 폴더 미리보기, 가져오기 진행률, 메타데이터 누락과 기존 확정 그림체 중복 후보를 확인할 수 있습니다.
- WebP EXIF와 NovelAI stealth 메타데이터에서 프롬프트·캐릭터·모델 정보를 복원합니다.
- 제작 기록·확정 그림체·공유 그림체의 로딩 진행률을 표시하고, 캐시되는 목록 전용 WebP 썸네일로 재조회 속도를 개선했습니다.
