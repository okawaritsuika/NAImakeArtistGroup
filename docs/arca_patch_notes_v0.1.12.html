01 그림체 이상형 월드컵 참가 갤러리부터 자동 저장, 우승 결과까지

원하는 그림체로 참가 명단 만들기

  • 상단의 이상형 월드컵 → 새로 만들기에서 이름, 필터, 참가 갤러리를 한 화면에서 설정합니다. 조건을 정하고 필터 적용을 누르면 후보 개수와 그림을 불러옵니다.
  • 공유 그림체와 확정 그림체를 함께 고를 수 있습니다. 로컬 이미지가 있는 항목을 대상으로 하며, 같은 공유 게시글이나 확정 항목에서는 조건에 맞는 대표 이미지 한 장을 보여 줍니다.
  • 2·4·8·16강 등의 규모로 자동 선택하거나 전부 참가를 선택할 수 있습니다. 전부 참가에는 128개 제한이 없으며, 참가 수가 2의 거듭제곱이 아니면 첫 라운드에 부전승을 배정합니다.
  • 자동 선택은 이미 고른 명단에 중복 없이 추가합니다. 최종 선택이 2개 이상이면 별도 선택 완료 단계 없이 바로 시작할 수 있습니다.

필터와 선택을 더 편하게

  • V5·V4.5와 세부 모델, V5 Medium, 모델 미상으로 후보를 좁힐 수 있습니다. 추천수 높은 순·낮은 순 정렬도 지원합니다.
  • 작가와 일반 태그를 포함할 태그 / 제외할 태그에서 함께 입력하며 자동완성을 사용할 수 있습니다. 포함한 태그는 모두 충족해야 하고, 제외한 태그는 하나라도 일치하면 빠집니다.
  • 태그 조건은 베이스 프롬프트만 비교합니다. 가중치·대소문자·밑줄과 공백 차이는 정리해서 비교하며, 네거티브와 캐릭터 프롬프트는 검사하지 않습니다.
  • 추천수 제외 조건은 공유 그림체에만 적용합니다. 숫자를 입력하면 해당 값 이하와 추천수 미상 항목이 제외되며, 확정 그림체는 이 조건의 영향을 받지 않습니다.
  • 필터나 출처를 바꿔도 기존 선택은 유지됩니다. ‘선택한 그림만’ 보기에서 명단을 다시 확인할 수 있습니다.

갤러리 확인과 대결 이어하기

  • 그림을 눌러 선택하거나, 마우스로 사각형 영역을 드래그해 여러 그림을 한 번에 고릅니다. 선택된 카드에서 시작하면 영역 안의 선택을 해제하고, Esc로 드래그를 취소할 수 있습니다.
  • 그림 크기를 조절하고 한 페이지에서 최대 60개를 볼 수 있습니다. 터치 화면에서는 스크롤과 탭 선택을 사용합니다.
  • 상세 보기에서 같은 게시글·확정 항목의 다른 그림과 이미지별 프롬프트를 확인합니다. 이전·다음 버튼과 방향키로 그림을 넘길 수 있고, 상세를 닫아도 선택 상태와 갤러리 위치를 유지합니다.
  • 매 경기 결과를 자동 저장합니다. 폴더형 목록에서 진행 중인 대회를 이어 하거나, 완료된 대회의 우승 그림과 전체 대결 기록을 다시 볼 수 있습니다.

원본 이미지 파일을 삭제하면 월드컵의 해당 그림도 표시되지 않습니다. 제목·프롬프트·대결 기록은 유지됩니다.

02 그림체 제작 화면과 편집 개선 작가 조건, 가중치, 프롬프트, 생성 조합을 더 명확하게

작업 화면 정리

  • 왼쪽 설정을 작가 조건 / 가중치로 나누고, 프롬프트와 생성 장수·랜덤 대상을 한 패널에서 설정하도록 정리했습니다.
  • 고정·캐릭터 프롬프트, 생성 파라미터, 공유·태그 조건과 고정 작가는 별도 편집 창에서 다룹니다.
  • 기존 생성 리모콘과 히스토리의 배치·조작을 다듬었습니다. 리모콘은 이동·접기·닫기가 가능하고 상단에서 다시 열 수 있습니다. 오른쪽 시계 아이콘으로 히스토리를 펼쳐 목록 안에서 기록을 탐색합니다.

가중치와 현재 조합 확인

  • 가중치 그래프에서 작가가 20명이어도 전체 분포를 함께 확인할 수 있습니다. 그래프를 누르거나 드래그해 값을 조절하고 적용합니다.
  • 현재 조합은 미리보기에서 선택된 작가·출처·실제 가중치를 먼저 보여 줍니다. 고정 후보 전체는 아래에서 펼쳐 편집할 수 있습니다.
  • 생성 결과의 조합 보기는 해당 이미지에 실제 사용한 명단을 보여 줍니다. 미리보기 명단과 생성 결과의 명단을 구분해 확인할 수 있습니다.
  • 고정 후보의 순서·가중치·랜덤 설정과 작가 추가 창을 더 간결하게 배치했습니다.

제외한 태그 복구

프롬프트 패널의 제외 N 탭에서 제외된 태그를 확인하고, 태그별로 복구하거나 전체 복구로 한꺼번에 되돌릴 수 있습니다.

03 NovelAI V5 Full Medium 지원 Medium 전용 설정 적용과 모델 정보 보존

생성 모델에서 V5 Full Medium을 선택할 수 있습니다. 이 모드에서는 다음 전용 설정을 적용합니다.

  • Steps 14 · Euler Ancestral · Karras로 고정합니다.
  • 전용 네거티브 프리셋을 적용하고 Rescale과 Variety+는 끕니다.
  • Prompt Guidance와 베이스·캐릭터 프롬프트는 수정할 수 있습니다.
  • 생성 기록·확정 그림체·비교군에도 Medium 모델 정보를 보존합니다.
  • 알려진 V5 이미지 메타데이터의 모델 구분을 보강해 Full·Curated·Medium을 구분하고, 공유 그림체와 월드컵의 모델 필터에도 반영합니다. 판별 근거가 없는 모델은 미상으로 유지합니다.

네거티브 입력 안내
Medium에서는 기존에 입력한 네거티브 프롬프트가 적용되지 않습니다. 다른 모델로 돌아가면 다시 편집할 수 있습니다.

04 공유 그림체 수집과 숫자 갱신 개선 새 글 재확인, 모델별 조회·추천 갱신, 중단 후 이어하기

당일과 다음날 수집 보완

  • 당일에는 새 글이 추가될 수 있으므로, 이미 수집한 날짜여도 다시 수집하면 검색합니다.
  • 다음날에도 전날을 수집 기간에 포함하면 첫 수집 이후 올라온 글을 확인합니다. 이미 받은 정상 이미지는 재사용합니다.

모델별 조회·추천 갱신

  • 조회·추천 갱신을 누르면 갱신할 모델을 고르는 창이 열립니다. 기본은 V5이며 전체·V4.5·세부 모델·모델 미상도 선택할 수 있습니다.
  • 선택 모델 이미지가 있는 저장 게시글을 대상으로 합니다. 이 대상은 화면의 날짜·목록 필터와 별개입니다.
  • 수집할 때 사용한 제목 검색어로 목록에서 여러 글의 숫자를 함께 확인하고, 목록에서 찾지 못한 글만 개별 확인합니다.
  • 진행 수·갱신 수·미확인 수와 개별 확인 단계를 표시합니다. 일시정지 후 계속할 수 있으며 중지·앱 종료 후 다시 시작할 때도 선택 모델을 유지합니다.
  • 이미지를 다시 내려받거나 저장한 프롬프트·메모를 바꾸지 않습니다. 삭제·접근 불가 등으로 숫자를 확인하지 못하면 기존 값을 유지합니다.
  • 요청 제한이나 계속되는 연결 오류가 발생하면 갱신한 값을 보존하고 중단합니다. R18 게시글이 대상에 포함되면 Chrome 로그인 연결이 필요합니다.

날짜 재확인은 해당 날짜를 포함해 수집을 실행할 때 동작합니다. 자동으로 매일 수집하는 기능은 아니며, 숫자 갱신 시간도 검색 목록 수와 사이트 응답에 따라 달라집니다.

05 다른 로컬 도구에서 작가 테스트에 이미지 추가 외부 프로그램 연동용 기능

같은 PC의 다른 프로그램에서 작가 이름과 PNG 한 장을 보내 NAI 작가 테스트에 추가할 수 있습니다. 처음 호출할 때 전용 그룹을 만들고 이후 이미지도 같은 그룹에 누적합니다.

POST /api/external-injection

  • 앱 서버가 실행 중인 같은 PC에서만 요청할 수 있습니다.
  • 작가 이름은 1~200자이며, 이미지 파일은 PNG · 업로드 크기 32MB 이하 · 가로/세로 각각 2048픽셀 이하를 지원합니다.
  • JPEG·WebP와 이미지 URL·파일 경로 입력은 지원하지 않습니다.
  • 추가한 결과는 기존 작가 테스트의 상세·이력·평가 기능으로 확인할 수 있습니다.
06 기존 데이터와 이미지 설치 안내 기존 data 폴더를 유지해 주세요
  • 기존 설정·평가·생성 기록·확정 그림체·로그인 프로필은 EXE 옆 data 폴더에 저장됩니다. 업데이트할 때 이 폴더를 그대로 유지해 주세요.
  • 검증된 공유 그림체 기본 데이터를 포함하고, 기존 데이터 폴더에는 새 기본 데이터를 병합합니다.
  • EXE에는 공유 이미지 원본이 들어 있지 않습니다. 필요한 이미지는 기존 Hugging Face에서 빠르게 받기 / 내 ZIP 설치 또는 아카라이브 직접 다운로드 기능으로 설치할 수 있습니다.
  • 이미지팩 설치 시 기존 정상 PNG·WebP는 재사용하고 없는 이미지를 추가합니다.
  • 배포 파일에는 개인 평가, NovelAI App Key, 개인 설정, 로그인 정보와 사용자가 생성한 이미지가 포함되지 않습니다.
