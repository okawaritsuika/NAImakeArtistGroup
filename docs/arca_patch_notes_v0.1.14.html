이번에 달라진 점

ACCOUNT

계정 정보를 암호화해 저장

아이디와 비밀번호 전체를 Windows DPAPI로 암호화합니다. 저장 정보는 같은 Windows 사용자 계정에서만 복원할 수 있습니다.

BROWSER

계정별 전용 Chrome

앱이 관리하는 계정별 로그인 창을 사용합니다. 로그인 화면 단계에 맞춰 정보를 한 번 입력하며, 반복해서 제출하지 않습니다.

CHOICE

확장 프로그램은 선택

계정 저장 방식으로 바로 시작하거나, 기존 확장으로 평소 Chrome의 로그인을 연결할 수 있습니다.

이렇게 시작하세요

처음 한 번 계정을 저장합니다.

공유 그림체 수집 › 🔞 게시판 로그인 › 계정 저장하고 자동 로그인

  1. 계정 입력

    위 메뉴를 펼쳐 아카라이브 아이디와 비밀번호를 입력합니다.

  2. 저장하고 로그인

    버튼을 누르면 전용 Chrome이 열리고 로그인 정보를 자동 입력합니다.

  3. 열린 창에서 인증 완료

    캡차나 추가 인증이 나오면 직접 완료하고, 앱의 로그인 연결 상태를 확인해 주세요.

  4. 다음에는 한 번의 클릭

    저장된 계정으로 로그인을 눌러 다시 연결합니다. 비밀번호를 매번 입력할 필요가 줄어듭니다.

R18 기간 수집에서 로그인이 필요하면 연결 후 대기 중인 수집을 자동으로 이어갑니다.
링크 추가·조회/추천 갱신은 먼저 로그인을 연결한 뒤 실행해 주세요.

연결이 계속 실패한다면

Chrome에서 로그인하는 단계와 앱이 게시판에 접속하는 단계는 별도입니다. 계정을 저장해도 인증서·프록시·사이트 차단 같은 앱의 네트워크 문제는 남을 수 있습니다.

ARCA_TLS보안 인증서 확인 실패입니다. PC 날짜·시간과 보안 프로그램의 HTTPS 검사 설정을 확인해 주세요.

ARCA_PROXY프록시 연결 실패입니다. Windows 또는 사용 중인 네트워크의 프록시 설정을 확인해 주세요.
