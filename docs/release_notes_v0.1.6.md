# v0.1.6 — 작가 예제와 공유 그림체 의존 생성 개선

## 주요 변경

- 작가 뽑기에서 게시물 기준일을 기본값·제공된 기준일·직접 지정 중에서 선택하고, 후보 수집과 제외 조건 검색에 함께 적용합니다.
- 평가 작가 카드에서 Danbooru 검색으로 이동하고, 대표 썸네일을 고화질 WebP로 받거나 갱신할 수 있습니다.
- 작가별 예제 그림을 추가 수집해 저장하고, 갤러리에서 확인·대표 썸네일 지정·삭제할 수 있습니다. 이미 받은 게시물은 중복 저장하지 않습니다.
- 공유 그림체 이미지의 작가 구성을 기준으로 최종 작가 수를 정하는 `공유 그림체 의존` 모드를 추가했습니다.
- 기준 그림체를 고정하거나 랜덤으로 선택하고, 기준 작가 선택 방식과 고정 작가·기준 그림체·평가 작가·다른 공유 그림체의 공급원 비율을 지정할 수 있습니다.
- 기준 그림체의 생성 설정과 출처를 생성 결과와 제작 기록에 함께 보관합니다.
- 제작 기록 히스토리, 접을 수 있는 생성 영역, 화면 위 생성 리모콘을 추가해 생성 결과를 다시 적용하거나 확정 그림체로 저장하고 삭제할 수 있습니다.
- 삭제 전 확인을 평가 예제·평가 기록·생성 기록·그림체·수집 그림체·비교군·비교 이미지·NovelAI App Key별로 설정할 수 있으며 기존 단일 설정도 호환됩니다.
- 입력 조건 도움말의 키보드 접근성과 화면 가장자리 표시를 개선하고, 숫자로 끝나는 태그와 가중치 프롬프트 구분자를 안정적으로 보정합니다.
