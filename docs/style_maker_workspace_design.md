# 그림체 제작 고정 작업 화면

- 승인된 2안: 왼쪽 고정 설정(작가 조건/가중치), 중앙 결과, 오른쪽 프롬프트·생성 및 접이식 히스토리. 하단 작업 막대와 페이지 세로 스크롤은 없다.
- 설정의 작가 수는 숫자와 −/＋, 허용 평점은 숫자만 있는 5개 다중 선택 버튼이다. 출처, 공유·태그 조건, 고정 작가, 작가 추가는 기존 기능을 보존한 모달에서 편집한다.
- 프롬프트 종류 선택과 생성 장수·랜덤 대상은 한 패널에 항상 함께 있다. 선행/고정/캐릭터/그룹 등 긴 편집은 추가 프롬프트 모달, 생성 파라미터는 별도 모달에서 편집한다. 기존 필드 ID, 저장 키, API 형식과 Medium 모델 제한을 유지한다.
- 생성 액션만 이동식 리모콘에 표시한다. 접기/닫기/상단에서 다시 열기, 방향키 이동, 창 경계 제한을 지원한다.
- 히스토리는 오른쪽 시계·되감기 아이콘으로 접고 펼친다. 전체 목록의 내부 스크롤만 허용하고 선택 정보를 아래에 고정한다. 선택·접기에서 목록 스크롤 위치를 보존한다.
- 가중치 그래프는 20개 슬롯을 전체 분포 막대로 표시한다. 그래프를 누르거나 드래그하면 즉시 편집되고 가로로 훑으면 중간 슬롯까지 연속 조절한다. 선택한 슬롯의 이름·값은 상세 입력과 동기화한다. 기존 profile 보간과 저장 형식을 유지하고 적용/취소를 구분한다.
- DOM: style-maker-tab은 toolbar + minmax(0,1fr) workspace. settings/generation/history는 header + minmax(0,1fr) body. settings/generation body는 overflow:hidden, history list와 긴 모달 body는 overflow:auto. 모달은 header/body/footer 독립 행, footer는 스크롤 밖이다.
- 1100px 이하에서 오른쪽 패널은 결과 위에 열리고 하나씩 사용한다. 760px 이하에서 설정도 오버레이로 열며, 기본으로 접는다. 560px 이하 높이에서는 여백을 줄인다. 모바일 버튼은 44px를 기준으로 한다.
- 빈 결과, 출처 로딩/오류, pending/disabled, 긴 이름·프롬프트와 다수 히스토리를 확인한다. 포커스 표시·모달 focus 복귀·Esc·Tab 순환을 제공한다.
- 조합 모달은 선택된 명단의 순번·이름·출처·실제 가중치를 먼저 표시하고 고정 후보 전체 편집은 접이식으로 분리한다. 왼쪽 `현재 조합`은 마지막 미리보기 추첨 스냅샷, 결과의 `조합 보기`는 화면에 표시된 생성 기록을 사용한다. 모달 열기·접기만으로 다시 추첨하지 않으며 미리보기와 생성 결과를 문구로 구분한다. 후보의 저장 형식과 생성 시 재추첨 규칙은 유지한다. 모달은 기존 header/body/footer 3행과 body 단일 스크롤을 유지하며 760px 이하에서는 행 안의 버튼을 다음 줄로 배치한다.
- 프롬프트 패널은 퀄리티/네거티브/제외 N의 3개 탭을 같은 편집 공간에서 전환한다. 제외 탭에서 태그별 복구와 전체 복구를 제공하고 비어 있으면 안내를 표시한다. 제외 목록만 남은 높이에서 스크롤하며 복구 버튼과 생성 설정은 항상 보인다. 텍스트/버튼 편집 모드를 유지하고 탭 방향키 탐색도 3개 탭을 순환한다.
- 조합과 고정 후보 편집 목록은 DOM 순서를 유지하는 flex-wrap으로 배치한다. 조합 카드는 이름과 값에 필요한 폭을 사용하고, 고정 후보 카드는 이름 입력 아래 한 줄에 순서·가중치·랜덤·삭제를 모은다. 긴 이름은 남은 폭에 맞춰 큰 카드가 되고, 좁은 화면에서는 필요한 컨트롤만 줄바꿈한다. 고정 열 수나 masonry 재정렬은 사용하지 않는다. 760px 이하에서도 들어갈 만큼 나란히 배치하되 터치 조작은 44px를 유지한다. 기존 선택/대기 구분·입력 이벤트·정렬·저장·모달 body 단일 스크롤은 유지한다.
- 작가 추가 모달은 최대 폭 460px, 내용에 맞는 높이로 표시한다. 이름 입력·저장된 작가 선택은 각각 한 행, 위치·가중치·랜덤은 한 행에 모은다. 추가/닫기는 스크롤 밖 footer에 두며 자동완성 목록은 높이를 제한한다. 기존 다중 작가 입력·저장된 작가 선택·자동완성·추가 동작은 유지한다.
- 검증: 관련 Node 행동 테스트, Python frontend 계약, 합성 데이터로 실제 JS를 실행한 1366×768,1024×768,900×500,390×700 및 breakpoint 렌더. 실제 생성/DB/과금 요청 없이 검증한다.
