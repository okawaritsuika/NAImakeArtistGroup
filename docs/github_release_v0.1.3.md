그림체 제작의 작가 선택 규칙과 가중치 그래프를 바로잡고, 그림체 관리·평가 관리·생성 안전 안내를 크게 개선한 버전입니다.

## 주요 변경

- 고정 작가를 전체 작가 수에 포함하고 남은 자리만 평가·공유 작가에서 선택
- 가중치가 포함된 NovelAI 작가 프롬프트 여러 개 일괄 입력 지원
- 사용자 그래프를 실제 전체 프롬프트 자리와 정확히 일치하도록 수정
- 여러 평가 태그마다 선택 인원을 지정하고 특정 수집 태그의 평가 작가를 제외하는 모달 추가
- 수집 프롬프트 자동/수동 선택 상자를 제거하고 매 장 랜덤 버튼 기준으로 통일
- 작가 → 퀄리티 → 고정 태그 순서로 프롬프트 구성
- 후보 수집 직후 첫 그림 표시 및 후보 소진 시 재수집 확인
- 평가 관리에서 쿼리 프롬프트 수정·삭제 지원
- 그림체 관리 목록·미리보기 확대, 오른쪽 상세 정보와 네거티브 토글 추가
- 여러 그림체를 미리 검토한 뒤 생성 이미지와 함께 일괄 삭제
- Opus 무료 기준인 28스텝·최대 1,048,576픽셀 초과 시 Anlas 차감 가능성 경고
- 삭제·재수집·이름 변경 등에 공통 디자인 모달 적용
