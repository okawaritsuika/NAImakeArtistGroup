# 공유 그림체 통계 로딩과 필터 배치

- 모델 선택은 추천수 필터의 첫 번째 셀에 둔다. 넓은 화면은 모델·추천수 빠른 선택·최소·최대·적용의 5열, 900px 이하는 2열이며 모델 셀은 전체 폭을 사용한다. 모든 입력과 버튼은 최소 44px 높이, 자식은 min-width:0이다.
- 요청 시작 시 결과 영역을 숨기고 선택 모델, 실제 집계 대상, 경과 시간을 안내한다. 비어 있다는 문구는 성공한 결과가 실제로 비어 있을 때만 표시한다. 실제 진행률을 알 수 없으므로 백분율이나 가상의 단계를 만들지 않는다.
- 결과 도착 시 결과 영역을 표시하고 진행 안내와 타이머를 제거한다. 오류 시 안내와 재시도 버튼을 표시한다. 모델·필터 변경은 대기 중에도 가능하며 이전 요청은 현재 화면이나 타이머를 변경하지 못한다.
- 진행 패널은 문서 흐름에 배치하며 화면을 덮지 않는다. 결과 영역 전체를 숨겨 이전 모델의 상세 열기를 방지한다. aria-busy, role=status와 aria-live를 사용하며 매초 바뀌는 경과 시간은 스크린리더 반복 안내에서 제외한다. 회전 표시는 reduced-motion을 따른다.
- 검증: 지연·실패·빈 결과·요청 순서 역전 Node 행동 테스트, DOM/grid 계약, 390·768·900·901·1280px 실제 렌더에서 버튼 가림과 가로 넘침 확인. API·DB·메타데이터는 변경하지 않는다.
